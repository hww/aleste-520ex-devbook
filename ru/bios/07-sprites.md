# 07-sprites.md — Спрайты и блочное копирование (BIOS.SPR)

## Назначение

Копирование блоков между RAM и VRAM, между разными страницами VRAM, и вывод/стирание спрайтов. Работает во всех четырёх режимах экрана, использует `GR_GET_ADR`, `WR_PIX`, `NEXT_LINE`, `TAB_CONV_*`, `TAB_ST_MSK_*` из `BIOS.GRP`.

**Важно:** `BIOS.SPR` **не подключён** к `BIOS.MAC` через `INCLUDE` в текущем комплекте. Это отдельная библиотека, которую нужно линковать после `BIOS.GRP` (потому что она использует его функции).

**Исходник:** `BIOS.SPR` (отдельно).

---

## Копирование RAM → VRAM

### `COPY_M_TO_V`

Копирует блок из памяти в VRAM.

```
Вход:  _X1 = длина строки в памяти (байт)
       _Y1 = адрес источника в памяти
       _X2 = X назначения в VRAM
       _Y2 = Y назначения в VRAM
       _DX = ширина по X
       _DY = высота по Y
       _SRC_PAGE = страница памяти-источника
       _DST_PAGE = страница VRAM-приёмника
       _WRT_MOD
       _CLIP, _XMN_CLIP, _XMX_CLIP, _YMN_CLIP, _YMX_CLIP
Выход: —
Изменяет: все регистры
```

**Что делает:** обрезает координаты по клиппингу (`TEST_XY_F`), затем для каждой строки читает байты из памяти (`IX`) и раскладывает их в пиксели VRAM через `WR_PIX`. Учитывает режим экрана (`COPY_MV_M_0` для 2 цветов, `COPY_MV_M_3` для 16 цветов, общий случай для 4 цветов).

**Пример (вывести 8-байтовую картинку в (10,20)):**
```asm
    LD   HL,8
    LD   (_X1),HL       ; длина = 8 байт
    LD   HL,BITMAP
    LD   (_Y1),HL       ; адрес источника
    LD   HL,10
    LD   (_X2),HL       ; X = 10
    LD   HL,20
    LD   (_Y2),HL       ; Y = 20
    LD   HL,8
    LD   (_DX),HL       ; ширина = 8
    LD   HL,1
    LD   (_DY),HL       ; высота = 1
    XOR  A
    LD   (_SRC_PAGE),A
    LD   (_DST_PAGE),A
    LD   (_WRT_MOD),A
    LD   (_CLIP),A
    CALL COPY_M_TO_V
...
BITMAP: DB 0FFH,81H,81H,81H,81H,81H,81H,0FFH
```

## Копирование VRAM → RAM

### `COPY_V_TO_M`

Копирует блок из VRAM в память.

```
Вход:  _X1 = X источника в VRAM
       _Y1 = Y источника в VRAM
       _X2 = длина строки в памяти (байт)
       _Y2 = адрес приёмника в памяти
       _DX = ширина по X
       _DY = высота по Y
       _SRC_PAGE = страница VRAM-источника
       _DST_PAGE = страница памяти-приёмника
Выход: —
Изменяет: все регистры
```

**Что делает:** `COPY_VM_GET` вычисляет число байт по X и число сдвигов, затем `COPY_VM_MAIN` для каждой строки читает байты VRAM (`IX`) и упаковывает их в байты памяти (`IY`). Учитывает режим экрана.

---

## Копирование VRAM → VRAM

### `COPY_V_TO_V`

Копирует блок внутри VRAM (между разными страницами или в пределах одной).

```
Вход:  _X1, _Y1 = координаты источника
       _X2, _Y2 = координаты приёмника
       _DX = ширина по X
       _DY = высота по Y
       _SRC_PAGE, _DST_PAGE
Выход: —
Изменяет: все регистры
```

**Что делает:** `COPY_VV_GET` вычисляет маски и число сдвигов (учитывая разницу X источника и приёмника), затем `COPY_VV_MAIN` копирует побайтово с учётом сдвига. Если сдвиг отрицательный (`COPY_VV_MAIN_L`), копирует справа налево.

**Пример (копировать прямоугольник 50×20 из (10,20) в (100,40)):**
```asm
    LD   HL,10
    LD   (_X1),HL
    LD   HL,20
    LD   (_Y1),HL
    LD   HL,100
    LD   (_X2),HL
    LD   HL,40
    LD   (_Y2),HL
    LD   HL,50
    LD   (_DX),HL
    LD   HL,20
    LD   (_DY),HL
    XOR  A
    LD   (_SRC_PAGE),A
    LD   (_DST_PAGE),A
    CALL COPY_V_TO_V
```

## Спрайты

### `DRAW_SPRITE`

Выводит спрайт 16×16 с маской и цветами.

```
Вход:  HL = Y, DE = X
       B = цвет переднего плана (FG)
       C = цвет фона (BG)
       _SDBPTR = указатель на Sprite Definition Block (SDB)
       _SPRBUF = указатель на буфер спрайта
       _DST_PAGE
Выход: —
Изменяет: все регистры
```

**Формат SDB:** 32 слова (64 байта). Каждая строка — два слова:
- `DW маска` (16 бит: 1 = рисовать пиксель)
- `DW биты` (16 бит: 1 = FG, 0 = BG)

**Формат буфера спрайта:** 16 строк × N байт (N зависит от режима: 3 для 2 цветов, 5 для 4 цветов, 9 для 16 цветов). Буфер хранит **фон под спрайтом**, чтобы `UNDRAW_SPRITE` мог восстановить.

**Что делает:**
1. Сохраняет фон под спрайтом в `_SPRBUF` (через `LDIR` из VRAM).
2. Для каждой строки SDB вызывает `DRW_S_VDI`, который побитово применяет маску и цвет, используя `WR_PIX_0` (Replace).
3. Восстанавливает VRAM-банк.

**Пример:**
```asm
    LD   HL,50      ; Y
    LD   DE,100     ; X
    LD   B,7        ; FG = белый
    LD   C,0        ; BG = чёрный
    LD   (_SDBPTR),SDB
    LD   (_SPRBUF),SPRBUF
    CALL DRAW_SPRITE
...
SDB:    ; 16 строк по 2 слова
    DW 0FFFFH, 0FFFFH   ; строка 0: маска вся 1, цвет весь 1
    DW 0FFFFH, 0FFFFH
    ; ...
SPRBUF: DS 16*9,0       ; буфер для 16 цветов
```

---

### `UNDRAW_SPRITE`

Стирает спрайт, восстанавливая фон из `_SPRBUF`.

```
Вход:  HL = Y, DE = X
       _SPRBUF = указатель на буфер спрайта
       _DST_PAGE
Выход: —
Изменяет: все регистры
```

**Что делает:** копирует `_SPRBUF+2` (фон) обратно в VRAM, строка за строкой. Использует `LDIR` с шагом `NEXT_LINE`.

**Пример (стереть спрайт):**
```asm
    LD   HL,50
    LD   DE,100
    LD   (_SPRBUF),SPRBUF
    CALL UNDRAW_SPRITE
```

---

### `DRW_S_VDI`

Внутренняя функция: рисует одну строку спрайта. Читает маску и биты из SDB (`IX`), применяет `_FG_COLOR`/`_BG_COLOR`, пишет через `WR_PIX_0`.

```
Вход:  IX = указатель на текущую строку SDB (4 байта)
       HL = адрес VRAM
       B = 16 (пикселей в строке)
       C = маска (из GR_GET_ADR)
Выход: —
```

**Логика:** для каждого из 16 пикселей сдвигает маску и биты, формирует байт цвета (`_FG_COLOR & C | D`), формирует маску (`E | C`), вызывает `WR_PIX_0`. Если бит маски = 0 — пиксель не рисуется (прозрачный).

## Внутреннее устройство

### `COPY_GET_PRM`

Вычисляет параметры для `COPY_M_TO_V`:
- `E'` = начальная маска
- `C'` = конечная маска
- `C` = число сдвигов
- `E` = число байт по X

Учитывает режим экрана (`TAB_ST_MSK_0` для 2 цветов, `TAB_ST_MSK_1` для 4/16 цветов).

### `COPY_VM_GET`

Вычисляет параметры для `COPY_V_TO_M`: число байт по X и число сдвигов.

### `COPY_VV_GET`

Вычисляет параметры для `COPY_V_TO_V`: начальную маску (`E'`), конечную маску (`A'`), число сдвигов (`C`), число байт по X (`E`). Если сдвиг отрицательный, `COPY_VV_MAIN` вызывает `NEG` и копирует справа налево (`COPY_VV_MAIN_L`).

### `COPY_VV_MAIN`

Копирует одну строку VRAM → VRAM. Для каждого байта источника читает два байта (текущий и следующий), сдвигает и собирает байт приёмника, вызывает `WR_PIX`.

## Ограничения

1. **Не подключён к `BIOS.MAC`.** Нужно добавить `INCLUDE BIOS.SPR` вручную после `BIOS.GRP`.
2. **Зависит от `BIOS.GRP`.** Использует `GR_GET_ADR`, `WR_PIX`, `NEXT_LINE`, `TAB_CONV_*`, `TAB_ST_MSK_*`. Линковать после `BIOS.GRP`.
3. **Спрайты только 16×16.** Формат SDB фиксирован (32 слова). Для спрайтов другого размера нужно писать свою функцию.
4. **Буфер спрайта должен быть достаточно большим.** Для режима 3 (16 цветов) нужно `16×9 = 144` байта на спрайт (плюс 2 байта заголовка `_SPRBUF+0/+1` — страница VRAM).
5. **Нет аппаратного блиттера.** Всё копируется побайтово через Z80. `COPY_V_TO_V` на большой области может занять заметное время.
