# 01-screen.md — Драйвер экрана (BIOS.SCR)

## Назначение

Управляет выводом символов, курсором, окнами вывода, роликом, цветами и палитрой. В отличие от CPC, здесь **нет фиксированного экрана** — вы задаёте окно через `SET_SIZE`, и весь вывод ограничивается его границами. Это ближе к MSX-подходу с программируемым окном, чем к CPC-овскому фиксированному 40×24 .

Драйвер поддерживает четыре режима экрана (640×200×2, 320×200×4, 640×200×4, 320×200×16), переключаемых через `SET_SCRMOD`. Каждый режим имеет свой layout VRAM и свою палитру по умолчанию.

**Исходник:** `BIOS.SCR` (подключается через `INCLUDE BIOS.SCR` в `BIOS.MAC`).

---

## Инициализация и режим экрана

### `SCR_INIT` (`L0069`)

Инициализация экрана. Копирует `SCRINITAB` в рабочую область (`WUP`…`GRPHED`) и вызывает `SET_SCRMOD` с `A=0, B=0, C=0` (режим 640×200×2, чёрный текст на чёрном фоне).

```
Вход:  —
Выход: —
Изменяет: все регистры
```
Вызывается из `INIT` BIOS. Вручную не вызывать.

---

### `SET_SCRMOD` (`L0081`)

Установка режима экрана. Переключает layout VRAM, палитру по умолчанию, регистры MC6845 и векторы `VRAMADR`/`WYWOD`/`WIDTH`/`ROLL3`/`ROLSTR`/`CURON`/`CUROFF`.

```
Вход:  A = режим: 0 = 640×200×2, 1 = 320×200×4, 2 = 640×200×4, 3 = 320×200×16
       B = цвет текста
       C = цвет фона
Выход: —
Изменяет: все регистры
```
После вызова экран очищается (`CLS`) и включается (`ENA_SCR`). Векторы перенастраиваются через `JP`-таблицу, поэтому старые вызовы `SYMBOL` автоматически попадают в новый код.

---

### `GET_SCRMOD` (`L0084`)

Возвращает текущий режим.

```
Вход:  —
Выход: A = режим (0–3)
```

---

### `DIS_SCR` / `ENA_SCR` (`L006C` / `L006F`)

Гашение и включение экрана (бит 3 `EXTPORT`).

```
Вход:  —
Выход: —
Изменяет: AF
```
Не очищает VRAM — только отключает вывод. Полезно для мгновенной очистки без мерцания: `DIS_SCR` → очистка → `ENA_SCR`.

---

## Вывод символов

### `SYMBOL` (`L0018`)

Основной способ печати. Выводит символ в текущую позицию курсора и обрабатывает управляющие коды (`CR`, `LF`, `TAB`, `DEL`, `ESC`-последовательности).

```
Вход:  A = код символа (0–255)
Выход: —
Изменяет: AF, BC, DE, HL
```
Если `A` — управляющий код (0–1FH), выполняется соответствующая функция из `CTRLTAB` (например, `0CH` = `CLS`, `0DH` = `CR`). Если `A=1BH` (`ESC`), начинается разбор ESC-последовательности.

**Пример:**
```asm
    LD  A,'H'
    CALL L0018      ; вывести 'H' в текущую позицию
    LD  A,0DH
    CALL L0018      ; CR
    LD  A,0AH
    CALL L0018      ; LF
```

---

### `WR_SYMBOL` (`L0072`)

Вывод символа в **заданную** позицию, без изменения курсора и без обработки управляющих кодов.

```
Вход:  A = код символа, H = X, L = Y
Выход: —
Изменяет: AF
```
Используется, когда нужно нарисовать символ в конкретном месте (например, в `SETUP` из `ROM.MAC`).

---

### `MESSAGE` (`L007B`)

Вывод строки с обработкой всех управляющих кодов, в текущую позицию курсора.

```
Вход:  DE = адрес строки (завершается 0)
Выход: —
Изменяет: все регистры
```
**Пример:**
```asm
    LD  DE,TEXT
    CALL L007B
    ...
TEXT: DB 'Hello, Aleste!',0
```

---

### `MESSAGE1` (`L0075`)

Вывод строки **без** обработки управляющих кодов, в позицию `[HL]`.

```
Вход:  DE = адрес строки (0), H = X, L = Y
Выход: —
Изменяет: все регистры
```
Быстрее `MESSAGE`, но не обрабатывает `CR`/`LF`/`TAB`. Используется в `SETUP` для вывода фиксированных строк.

---

### `FMESSXY` (`L0162`)

Быстрый вывод строки в позицию `[HL]` **напрямую в VRAM**, минуя буферы и обработку режимов. Используется в `SETUP` для скорости.

```
Вход:  DE = строка (0), H = X, L = Y
Выход: —
Изменяет: все регистры
```
Не поддерживает `MODES` (подчёркивание, негатив, широкий, сетчатый) и `SYMMOD` (AND/OR/XOR). Только прямая запись.

---

### `SET_FONT` / `GET_FONT` (`L0087` / `L008A`)

Вид шрифта: подчёркивание, негатив, широкий, сетчатый.

```
Вход:  A = битовая маска: bit0 подчёркивание, bit1 негатив,
                         bit2 широкий, bit3 сетчатый
Выход: (GET) A = текущая маска
```
`SET_FONT` только записывает `MODES`; реальное применение — в `SYMBOL2` при выводе.

---

### `SET_MODE` / `GET_MODE` (`L008D` / `L0090`)

Режим вывода символа: `NORMAL`, `AND`, `OR`, `XOR`.

```
Вход:  A = 0 (NORMAL), 1 (AND), 2 (OR), 3 (XOR)
Выход: (GET) A = текущий режим
```
В режиме `XOR` символ инвертирует фон, не затирая его. Это **не аппаратная фича**, а программная — `WYWOD_XOR`/`WYWODH_XOR` в `BIOS.SCR`.

**Пример (мигающий курсор через XOR):**
```asm
    LD  A,3
    CALL L008D      ; SET_MODE XOR
    LD  A,' '
    CALL L0018      ; инвертировать знакоместо
    ; ... задержка ...
    LD  A,' '
    CALL L0018      ; вернуть обратно
```

## Окно вывода

### `SET_SIZE` (`L0093`)

Установка границ окна вывода. Весь последующий вывод `SYMBOL`/`MESSAGE` ограничивается этим окном, `SCROLL` работает только внутри него.

```
Вход:  H = X левого верхнего угла, L = Y
       B = высота, C = ширина
Выход: —
Изменяет: все регистры
```
Координаты корректируются по текущему режиму экрана (`SETSIZE0`). Курсор перемещается в левый верхний угол окна.

**Пример (окно 20×10 в правом нижнем углу):**
```asm
    LD  HL,0028H    ; X=40, Y=0
    LD  BC,0A14H    ; высота=10, ширина=20
    CALL L0093
```

---

### `GET_SIZE` (`L0096`)

Возвращает текущие границы окна.

```
Вход:  —
Выход: HL = X,Y левого верхнего угла
       BC = высота, ширина
Изменяет: AF
```

---

### `SCROLL` (`L0078`)

Ролик экрана внутри окна. Если окно совпадает с полным экраном, используется **аппаратный ролик** через `SET_BASE` (быстро). Иначе — программный (`L_SCROL1`/`H_ROLL`).

```
Вход:  B = 0 (ролик вниз), иначе (ролик вверх)
Выход: —
Изменяет: все регистры
```
Вызывается автоматически из `SYMBOL` при переполнении окна.

---

## Курсор

### `CUR_INIT` (`L00CC`)

Инициализация курсора: `MODECUR=0A0H` (курсор включён, вставка выключена, звук выключен), цвет `0FH`, форма `CURFORM`.

```
Вход:  —
Выход: —
```

---

### `ENA_CUR` / `DIS_CUR` (`L00CF` / `L00D2`)

Включение/выключение курсора (бит 7 `MODECUR`).

```
Вход:  —
Выход: —
Изменяет: AF
```

---

### `INSERT_ON` / `INSERT_OFF` (`L00D5` / `L00D8`)

Режим вставки (бит 6 `MODECUR`). Меняет форму курсора (`CURNORM` ↔ `CURINS`).

```
Вход:  —
Выход: —
Изменяет: AF
```

---

### `SET_CUR` / `GET_CUR` (`L00DB` / `L00DE`)

Установка/чтение позиции курсора.

```
Вход:  H = X, L = Y (SET_CUR)
Выход: H = X, L = Y (GET_CUR)
```
`SET_CUR` добавляет смещение окна (`WUP`) и корректирует через `CSRPOS`. `GET_CUR` вычитает `WUP`.

---

### `PLACE_CUR` / `ERASE_CUR` (`L00E7` / `L00EA`)

Вывод/гашение курсора. Сохраняет фон в `BUFCUR`, затем XOR-восстанавливает.

```
Вход:  —
Выход: —
Изменяет: все регистры
```
Вызывается из `INPUT` (блокирующий ввод) автоматически.

---

### `SET_CURINK` / `GET_CURINK` (`L00E1` / `L00E4`)

Цвет курсора.

```
Вход:  A = цвет (0–15)
Выход: (GET) A = цвет
```

---

## Цвета и палитра

### `SET_INK` / `GET_INK` (`L00B1` / `L00B4`)

Цвет символов.

```
Вход:  A = цвет (0–15)
Выход: (GET) A = цвет
```
В режиме 0 (`640×200×2`) цвет преобразуется в 2-битную маску через `PALINITB1`. В режимах 1–2 — в 4-битную, в режиме 3 — в 8-битную.

---

### `SET_PAPER` / `GET_PAPER` (`L00B7` / `L00BA`)

Цвет фона.

```
Вход:  A = цвет (0–15)
Выход: (GET) A = цвет
```

---

### `SET_BORDER` / `GET_BORDER` (`L00BD` / `L00C0`)

Цвет бордюра (0–63).

```
Вход:  A = цвет (0–63)
Выход: (GET) A = цвет
```
Пишет напрямую в порт `7FFFH` (биты 0–5).

---

### `PAL_INIT` (`L00C3`)

Инициализация палитры по умолчанию для текущего режима. Вызывается из `SET_SCRMOD`.

```
Вход:  —
Выход: —
```

---

### `SET_PAL` / `GET_PAL` (`L00C6` / `L00C9`)

Установка/чтение палитры для конкретного цвета.

```
Вход:  A = номер цвета, E = значение палитры (SET_PAL)
Выход: (GET) E = значение палитры
```
Пишет в порт `7FFFH`: сначала номер цвета, затем `E | 40H`.

---

## PGT (знакогенератор)

### `SET_PGT` / `GET_PGT` (`L0099` / `L009C`)

Установка/чтение адреса и страницы знакогенератора.

```
Вход:  HL = адрес PGT, A = номер страницы (SET_PGT)
Выход: HL = адрес, A = страница (GET_PGT)
```
По умолчанию `PGTADR = ALEST`, `PGTPAGE = 8`.

---

## Страницы VRAM и база

### `SET_VPAGE` / `GET_VPAGE` (`L00A5` / `L00A8`)

Установка/чтение логической и физической страницы VRAM.

```
Вход:  A = bit0-1 логическая страница, bit4-5 физическая (SET_VPAGE)
Выход: A = текущее значение (GET_VPAGE)
```
В режимах 0–1 используется 2 логические страницы, в режимах 2–3 — 1 (из-за удвоенного размера).

---

### `SET_BASE` / `GET_BASE` (`L00AB` / `L00AE`)

Установка/чтение адреса начала изображения. Если физическая страница совпадает с логической, программирует MC6845 (регистры 12/13).

```
Вход:  HL = адрес (SET_BASE)
Выход: HL = адрес (GET_BASE)
```

---

## Прочее

### `BEEP` (`L00A2`)

Звуковой сигнал. Три вида (1, 2, 3), параметры (тон, громкость) читаются из RTC (регистр `1BH`).

```
Вход:  —
Выход: —
Изменяет: все регистры
```
Использует каналы A и B AY8910.

---

### `INVERT` (`L0165`)

Инверсия знакомест в VRAM.

```
Вход:  HL = X,Y, B = количество знакомест
Выход: —
Изменяет: все регистры
```
Инвертирует 8 байт (одно знакоместо) для `B` знакомест подряд.

---

### `CLS` (`L007E`)

Очистка экрана цветом фона.

```
Вход:  —
Выход: —
Изменяет: все регистры
```

---

### `DEL` (`L007F`? — внутренняя)

Удаление символа под курсором со сдвигом строки влево. Вызывается через `SYMBOL` при `A=7FH`.

## Переменные драйвера

| Адрес | Имя | Назначение |
|-------|-----|-----------|
| `0FE05H` | `WUP` | Верхняя граница окна |
| `0FE06H` | `WLEFT` | Левая граница окна |
| `0FE07H` | `WDOWN` | Нижняя граница окна |
| `0FE08H` | `WRIGHT` | Правая граница окна |
| `0FE09H` | `CSRY` | Y курсора |
| `0FE0AH` | `CSRX` | X курсора |
| `0FE0BH` | `PGTPAGE` | Страница PGT |
| `0FE0CH` | `PGTADR` | Адрес PGT |
| `0FE0EH` | `SCRMOD` | Режим экрана |
| `0FE0FH` | `MODES` | Вид шрифта |
| `0FE10H` | `SYMMOD` | Режим вывода |
| `0FE11H` | `BASE` | Адрес начала экрана |
| `0FE13H` | `VPAGE` | Страницы VRAM |
| `0FE14H` | `INK` | Цвет символов |
| `0FE15H` | `PAPER` | Цвет фона |
| `0FE16H` | `BORDER` | Цвет бордюра |
| `0FE17H` | `BUFSYM1` | Буфер PGT (8 байт) |
| `0FE1FH` | `BUFSYM2` | Буфер вывода (32 байта) |
| `0FE3FH` | `SAVECUR` | Сохранённая позиция курсора |
| `0FE41H` | `ESCBUF` | Буфер ESC-последовательности |
| `0FE49H` | `ESCADR` | Указатель в `ESCBUF` |
| `0FE4BH` | `ESCCNT` | Счётчик ESC |
| `0FE4CH` | `GRPHED` | Флаг псевдографики |
| `0FE4DH` | `MODECUR` | Режим курсора |
| `0FE4EH` | `CURINK` | Цвет курсора |
| `0FE4FH` | `BUFCUR` | Буфер фона курсора |
| `0FE6FH` | `CURNORM` | Форма обычного курсора |
| `0FE77H` | `CURINS` | Форма курсора вставки |
| `0FE7FH` | `PALTAB` | Таблица палитр |
