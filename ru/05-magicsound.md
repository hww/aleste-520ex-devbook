# 05. Magic Sound Board

Magic Sound Board — это плата расширения для Aleste 520EX, разработанная той же компанией Patisonic. Она даёт то, чего у базовой машины нет: четырёхканальный цифровой звук с DMA.

Штука редкая. Плата выпускалась ограниченно, и найти её сейчас сложно. Но если она у тебя есть — этот раздел расскажет, как с ней работать.

Если платы нет — раздел можно пропустить. Базовая Aleste работает со звуком через AY-3-8910, и этого для большинства задач достаточно.

## Что умеет Magic Sound

Плата — это четырёхканальный проигрыватель оцифрованного звука. Не синтезатор, а именно семплер: она воспроизводит готовые цифровые записи.

Характеристики:

- **4 канала** независимого воспроизведения.
- **8 бит на семпл** — стандартная глубина для того времени.
- **7 бит на громкость** каждого канала (D0–D6). Рабочий диапазон — **1..63**; значения **0 и 1 — особые** (трактуются как `40H` = 64, «максимум/спецзначение», см. ниже).
  <!-- FIX: было «6 бит, 1..64, 0 — особое». По коду MA_START: порт принимает 7 бит (D0–D6), 40H = бит 6. Рабочий диапазон 1..63; 0 и 1 -> 40H. -->
- **16-битный таймер частоты** на каждый канал — можно задавать скорость воспроизведения с высокой точностью.
- **Два чипа 8254** (программируемых таймера), а не один: каналы A/B/C обслуживает первый, каналы D/E — второй (см. раздел «Порты»).

Плата работает через DMA: она читает данные напрямую из памяти Aleste, не нагружая процессор. Процессор только настраивает каналы и запускает воспроизведение.

Именно поэтому плата требует расширенного порта расширения Aleste с дополнительными DMA-пинами. На обычном CPC она работать не будет.

## Зачем это нужно

Основное применение — воспроизведение музыки в формате **STM** (Scream Tracker). Это формат трекерной музыки, популярный в MSX-мире и на PC.

STM-файлы содержат семплы (записанные звуки) и партитуру: какой канал, когда, что играет. Magic Sound читает эти данные и воспроизводит.

Помимо музыки, плата подходит для:

- Звуковых эффектов высокого качества (выстрелы, взрывы, голос).
- Воспроизведения речи.
- Любых задач, где нужно проиграть записанный звук, а не сгенерировать его.

AY-3-8910 так не умеет: он генерирует простые волны. Magic Sound играет то, что записано.

Плата использует несколько портов ввода-вывода. Адреса выбираются так, чтобы не конфликтовать с базовыми устройствами Aleste.

|---------|-----------------------|---------------------------------|-------------------------------------|-------------------|----|
| `#FXDX` | Выбор платы           |                                 |                                     |                   | —  |
| `#F8DX` | DMA-контроллер        | [8237](../datasheets/M8257.PDF) | A[3..0]                             |                   | RW |
| `#F9DX` | Таймеры               | [8254](../datasheets/8254.PDF)  | A[2] номер таймера, A[1..0] регистр |                   | W  |
| `#FADX` | Управление громкостью |                                 | A[1..0] канал                       | D[6..0] громкость | W  |
| `#FBDX` | Маппер                |                                 | A[1..0] канал, A[3..2] байт канала  | D[4..0] страница  | W  |

Разберём каждый.

### `#FXDX` — выбор платы

Этот порт активирует плату. Пока в него не записали определённое значение, плата не отвечает на обращения. Так сделано, чтобы не мешать другим устройствам.

Точное значение, которое нужно записать, зависит от реализации платы. В оригинальной документации оно указано не полностью.

> **Из кода:** в исходнике `.Z80` **нет ни одной записи в `#FXDX`**. Инициализация (`INI_PRT`) трогает только `#F9Dx`, `#F8Dx`, `#FA`/`#FB` через макросы. То есть либо в этой версии прошивки выбор платы не нужен, либо он делается на уровне железа/расширенного порта. **Не полагайся на `#FXDX` как на обязательный шаг** — в приведённом коде он не используется.

### `#F8DX` — DMA-контроллер 8237

Это микросхема 8237 — стандартный DMA-контроллер, известный по PC. Он управляет прямым доступом к памяти: читает данные из RAM Aleste и передаёт их в звуковой тракт без участия процессора.

Младшие 4 бита адреса (`X` в `#F8DX`) выбирают регистр контроллера. Данные идут через младшие 8 бит.

8237 — микросхема сложная. Полное описание — в даташите. Основные регистры, **как они разведены в коде**:

| Адрес   | Назначение                        |
| ------- | --------------------------------- |
| `#F8D0` | адрес канала A (2 байта, LSB/MSB) |
| `#F8D1` | длина канала A (2 байта, LSB/MSB) |
| `#F8D2` | адрес канала B                    |
| `#F8D3` | длина канала B                    |
| `#F8D4` | адрес канала C                    |
| `#F8D5` | длина канала C                    |
| `#F8D6` | адрес канала D                    |
| `#F8D7` | длина канала D                    |
| `#F8D8` | команда / статус (DMACOM)         |
| `#F8DA` | маска каналов (DMAMASK)           |
| `#F8DB` | режим (DMAMOD)                    |
| `#F8DD` | сброс (DMARES)                    |

**Режимы (`DMAMOD`), используемые в коде:** `48H`, `49H`, `4AH`, `4BH` для каналов A/B/C/D соответственно. Раскладка байта 8237: `01 0 0 10 cc` — single mode, инкремент адреса, без autoinit, тип передачи «read» (память → устройство), номер канала `cc` (00=A, 01=B, 10=C, 11=D).

**Режимы при перепрограммировании по NMI (`MA_NMI`):** `58H`, `59H`, `5AH`, `5BH` для A/B/C/D соответственно. Отличаются от `48H..4BH` **битом 4 = 1 (autoinit enable)** — чтобы 8237 автоматически перезапускался после цепочки.
<!-- FIX: добавлено про 58H..5BH — в исходном документе их не было, а в коде они есть. -->

**Маска (`DMAMASK`):** в `INI_PRT` последовательно пишутся `05H, 04H, 07H, 06H`. Это **запрет каналов B, A, D, C** (в таком порядке):

- `05H` = set mask, канал 1 (B);
- `04H` = set mask, канал 0 (A);
- `07H` = set mask, канал 3 (D);
- `06H` = set mask, канал 2 (C).

Порядок не важен (все четыре всё равно запрещены), но **комментарий «запрет каналов 0,1,2,3» был бы неверен** — фактический порядок B, A, D, C.
<!-- FIX: исправлено «запрет 0,1,2,3» -> «запрет B,A,D,C». -->

Перед запуском канала в него пишется номер канала (`DST` = 0,1,2,3), что **снимает** маску.

**Команда (`DMACOM`):** инициализируется нулём.

**Сброс (`DMARES`):** запись 0 при инициализации.

Программист настраивает 8237 так, чтобы он читал данные семпла из памяти и отправлял их в DAC.

**Ограничение длины:** размер непрерывного семпла — 64 КБ (16-битный счётчик). Для более длинных семплов требуется перепрограммирование по NMI (см. ниже).

### `#F9DX` — таймеры 8254

> **Важно:** в исходнике используются **два чипа 8254**, а не один.

Раскладка портов из кода:

| Порт    | Назначение                                   |
| ------- | -------------------------------------------- |
| `#F9D8` | канал 0 (A) первого 8254                     |
| `#F9D9` | канал 1 (B) первого 8254                     |
| `#F9DA` | канал 2 (C) первого 8254                     |
| `#F9DB` | управляющий регистр первого 8254 (`TIMUP0`)  |
| `#F9D4` | канал 0 (D) второго 8254                     |
| `#F9D5` | канал 1 (E) второго 8254                     |
| `#F9D7` | управляющий регистр второго 8254 (`TIMUP1`)  |

**Формула адреса:** `A[2]` — номер 8254 (0 = первый, 1 = второй), `A[1..0]` — регистр (00 = канал 0, 01 = канал 1, 10 = канал 2, 11 = управляющий). Отсюда:

- `#F9D8` = `1000` → A[2]=0, A[1..0]=00 → канал 0 первого;
- `#F9D4` = `0100` → A[2]=1, A[1..0]=00 → канал 0 второго;
- `#F9DB` = `1011` → A[2]=0, A[1..0]=11 → управляющий первого;
- `#F9D7` = `0111` → A[2]=1, A[1..0]=11 → управляющий второго.

То есть звуковые каналы A/B/C тактуются первым 8254, канал D — каналом 0 второго 8254, а канал E (`#F9D5`) — каналом 1 второго. Канал E в коде инициализируется значением `4` и, судя по всему, обслуживает DAC/служебную функцию.

**Инициализация (`INI_PRT`):**

- первый 8254: `34H`, `74H`, `B4H` — каналы 0,1,2, **mode 2** (rate generator), LSB then MSB;
- второй 8254: `34H`, `76H` — каналы 0,1. При этом `34H` — **mode 2**, а `76H` — **mode 3** (square wave), а не mode 2.
- канал E: значение `4`.

<!-- FIX: явно указано, что 76H — mode 3, а не mode 2. В исходном документе это было упущено. -->

**Важно:** после сброса таймеры не работают, пока в них не запишут начальные значения. Нужно инициализировать 8254 перед использованием.

Каждый канал таймера задаёт частоту воспроизведения для соответствующего звукового канала. Чем выше частота, тем выше качество звука (и тем больше данных в секунду).

**Формула частоты (из кода `RET_DIV`/`IDIV_1`):** частота канала получается делением частоты семпла на делитель ноты. Делители фиксированы таблицей `ST_DIV` (12 значений на октаву):

```
766H, 6FCH, 697H, 639H, 5DFH, 58BH,
53BH, 4F0H, 4A9H, 466H, 427H, 3EBH
```

Старший полубайт ноты задаёт сдвиг (октаву), младший — индекс в таблице. Этой конкретики в прежней документации не было.

**Уточнение:** `RET_DIV` читает **не** `ST_DIV` напрямую, а `I_DIV` — таблицу, полученную умножением `ST_DIV` на коэффициент инструмента (`IDIV_1`/`MUL`). `ST_DIV` — это «стандартные» делители, а `I_DIV` — «подогнанные» под частоту конкретного инструмента.

### `#FADX` — управление громкостью

Этот порт задаёт громкость каждого из четырёх каналов.

- Младшие 2 бита адреса (`X` в `#FADX`) — номер канала (0–3).
- Биты данных **D0–D6** (7 бит) — громкость.

> **Уточнение из кода:** порт принимает **7 бит** (D0–D6), а не 6. Рабочий диапазон — **1..63**; значения **0 и 1 трактуются как `40H` (64)** — «максимум/спецзначение», а не тишина. В `MA_START`:
>
> ```
> LD A,(SNG_VOL+SEG)
> SUB 1
> JR Z,MA_5      ; SNG_VOL = 1 -> 40H
> JR NC,MA_4     ; SNG_VOL >= 2 -> как есть
> MA_5: LD A,40H ; SNG_VOL = 0 -> 40H
> MA_4: OUT (PVOL),A
> ```
>
> То есть:
>
> - `SNG_VOL = 0` → `40H` (64);
> - `SNG_VOL = 1` → `40H` (64);
> - `SNG_VOL >= 2` → `SNG_VOL` (как есть).
>
> Для сравнения с пиковым индикатором (`PIK_VOL`) используется `AND 3FH`, т.е. младшие 6 бит — громкость, а бит 6 — спецфлаг.
>
> Практически: **используй 2..63 для обычной громкости; 0 и 1 дадут «максимум»**.

Громкость 2 — тихо, 63 — громко, 0/1 — «максимум» (спецзначение).

### `#FBDX` — маппер

Этот порт управляет тем, из какого банка памяти читаются данные для каждого канала.

- Младшие 2 бита адреса (`A[1..0]`) — номер канала (0–3).
- Биты `A[3..2]` — номер байта внутри канала (0–3).
- Младшие 5 бит данных (`D[4..0]`) — номер страницы памяти (в инвертированном виде).

Базовые адреса для каналов:

- канал A: `#FBD0..#FBD3`;
- канал B: `#FBD4..#FBD7`;
- канал C: `#FBD8..#FBDB`;
- канал D: `#FBDC..#FBDF`.


> **Уточнение из кода:** запись в маппер идёт **4 байтами на канал** (а не «4 байта на все каналы»), причём **инвертированными** (`CPL`) и **убывающими на 1**:
>
> ```
> LD A,(S_MAP)
> CPL
> OUT (#FBD0),A   ; байт 0 канала A
> DEC A
> OUT (#FBD1),A   ; байт 1 канала A
> DEC A
> OUT (#FBD2),A   ; байт 2 канала A
> DEC A
> OUT (#FBD3),A   ; байт 3 канала A
> ```
>
> То есть маппер задаёт **4 последовательные страницы на канал**, начиная с инвертированной базовой. Для канала B — то же самое, но в `#FBD4..#FBD7`; для C — в `#FBD8..#FBDB`; для D — в `#FBDC..#FBDF`.

Заметь: номер страницы **инвертирован**. То есть если хочешь указать страницу 5, надо записать не 5, а обратное значение. Это особенность платы, о ней легко забыть.

После сброса таймеры не работают, пока в маппер не будет сделана первая запись. Это своего рода «запуск» платы.

## NMI по завершении DMA

Когда DMA-контроллер 8237 завершает передачу (сигнал TC — Terminal Count), он генерирует **NMI** — немаскируемое прерывание.

Это значит, что после окончания воспроизведения семпла процессор получает прерывание. Программа может на это отреагировать: запустить следующий семпл, обновить состояние, остановить канал.

> **Механика из кода:** в обработчике `NMI` читается регистр `#F8D8` (`DMACOM`, он же статус) в `E`. Затем **четыре раза** вызывается макрос `MA_NMI` (для каналов A, B, C, D), и каждый раз делается `RRC E` — так проверяются **биты 0, 1, 2, 3** статуса (TC каналов A, B, C, D соответственно). Если соответствующий бит не установлен — выход из макроса. Если установлен и у канала есть флаг `F_RESTART` — из `NMI_START`/`NMI_LENGHT` перезаписываются адрес и длина, сбрасывается `F_RESTART`, ставится режим (`58H..5BH`, autoinit) и снимается маска. Так реализуется **цепочка семплов** (продолжение воспроизведения за пределами 64 КБ).

NMI — это не обычное прерывание. Его нельзя замаскировать, и оно имеет приоритет над всеми остальными. Обработчик NMI должен быть коротким и аккуратным.

## Как это программируется

Общая схема работы с Magic Sound такая.

1. **Инициализация.** Настроить порты платы, включить её (если требуется `#FXDX` — см. оговорку выше), инициализировать оба 8254.
2. **Подготовка данных.** Загрузить семплы в память Aleste. Обычно они лежат в отдельных банках.
3. **Настройка каналов.** Для каждого канала задать:
   - адрес семпла в памяти (в регистры 8237),
   - длину семпла,
   - частоту воспроизведения (через 8254),
   - громкость (через `#FADX`),
   - страницы памяти (через `#FBDX`, 4 байта на канал).
4. **Запуск DMA.** Настроить 8237 на чтение из памяти и запись в DAC. Дать команду на старт (снять маску).
5. **Обработка NMI.** Когда семпл закончился, придёт NMI. В обработчике — запустить следующий или остановиться.

Точные последовательности записей в порты — в даташитах на 8237 и 8254. Это стандартные микросхемы, документации по ним много.

## Сложности

Magic Sound — устройство не для начинающих. Вот почему.

**8237 — сложная микросхема.** Программирование DMA требует понимания регистров, режимов, приоритетов, выравнивания адресов. Ошибка в одном бите — и передача не пойдёт или пойдёт не туда. Размер непрерывного семпла равен 64 КБ, для более длинных семплов требуется перепрограммирование по NMI.

**NMI — опасное прерывание.** Обработчик NMI должен быть очень коротким и не использовать ресурсы, которые могут быть заняты. Если NMI случится во время работы с диском или с критичной секцией — могут быть проблемы.

**Инвертированный номер страницы.** Легко забыть, что номер страницы в `#FBDX` инвертирован, да ещё и пишется **4 байтами на канал** (а не одним). В результате канал читает не туда.

**Таймеры после сброса не работают.** Нужно обязательно инициализировать оба 8254, иначе ничего не зазвучит.

**Два чипа 8254.** Каналы A/B/C и D/E обслуживаются разными чипами с разными базами (`#F9D8` vs `#F9D4`) и разными управляющими регистрами (`#F9DB` vs `#F9D7`). Не перепутай.

**`76H` — mode 3, а не mode 2.** Канал E тактируется меандром (square wave), а не rate generator. Это важно для расчёта частоты.

## Что делать, если платы нет

Если Magic Sound у тебя нет — не расстраивайся. AY-3-8910 даёт три канала синтеза, и для большинства задач этого хватает. Музыка, звуковые эффекты, простые мелодии — всё это делается на AY.

Magic Sound — это шаг вперёд по качеству, но не обязательное условие для программирования на Aleste.

Если хочешь поэкспериментировать с цифровым звуком без платы — можно попробовать программный софт-микшер на AY. Это медленнее и качество хуже, но работает на любой машине.

## Формат STM (из кода загрузчика)

- Расширение файла — `.STM` (в коде принудительно выставляется в FCB: `S`,`T`,`M`).
- Проверки при загрузке: байт `DATA+1EH == 2` (версия) и `DATA+1DH == 2` (число паттернов); при несовпадении — ошибка.
- `DATA+32` (`20H`) — темп (используется для `TEMP_CONT`/`TEMP_PE`).
- `DATA+33` (`21H`) — число инструментов (по нему считается число блоков для загрузки).
- `DATA+34` (`22H`) — общая громкость (`VOL_1234`).
- Инструменты: 32 байта на запись (`INST`), обрабатывается **31 инструмент** (`B=31` в `INI_DIV`).
- Паттерн: **64 строки** (`CP 40H` в `NEXT_NOT`), 4 канала, смещение **4 байта на канал** внутри строки.
- Загрузка идёт блоками по 32 записи (`BDOS 27H`), адрес буфера — `DATA` (`#2000`).

### A.3. Обработчик NMI (`NMI`)

```asm
NMI:
  PUSH HL
  PUSH DE
  PUSH BC
  PUSH AF
  LD BC,#F8D8
  IN E,(C)         ; статус DMA
  ; четыре вызова MA_NMI — по одному на канал
  MA_NMI SEG_A,DMA_A,58H,0
  MA_NMI SEG_B,DMA_B,59H,1
  MA_NMI SEG_C,DMA_C,5AH,2
  MA_NMI SEG_D,DMA_D,5BH,3
  POP AF
  POP BC
  POP DE
  POP HL
  RETN
```

Внутри `MA_NMI` (макрос):

```asm
  RRC E            ; carry = следующий бит статуса (TC канала)
  JR NC,MA_QUIT
  LD A,(F_RESTART+SEG1)
  OR A
  JR Z,MA_QUIT
  LD HL,(NMI_START+SEG1)
  LD BC,DMA1
  OUT (C),L
  OUT (C),H
  INC C
  LD HL,(NMI_LENGHT+SEG1)
  OUT (C),L
  OUT (C),H
  SUB A
  LD (F_RESTART+SEG1),A
  LD BC,DMAMOD
  LD A,DMOD1       ; 58H..5BH (autoinit)
  OUT (C),A
  LD BC,DMAMASK
  LD A,DST1        ; 0..3
  OUT (C),A
MA_QUIT:
```

### A.4. Расчёт делителя ноты (`RET_DIV`)

```asm
; A = нота (младший полубайт — индекс, старший — октава)
; IX = канал; результат HL = делитель
RET_DIV:
  PUSH AF
  AND #0F
  LD L,A
  LD H,0
  ADD HL,HL          ; *2
  LD E,(IX+SEK_SAMP)
  LD D,(IX+SEK_SAMP+1)
  ADD HL,DE          ; + адрес инструмента
  LD DE,490H-30H
  ADD HL,DE
  LD E,(HL)
  INC HL
  LD D,(HL)
  EX DE,HL           ; HL = делитель из I_DIV
  POP AF
  SRL A
  SRL A
  SRL A
  SRL A              ; A = октава
  AND 7
  RET Z
  LD B,A
RED_0:

  RR L
  DJNZ RED_0

```
