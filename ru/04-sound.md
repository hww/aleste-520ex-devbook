# 04. Звук

Звук в Aleste — это микросхема AY-3-8910. Та же самая, что
стояла в Amstrad CPC, MSX, ZX Spectrum 128 и куче других машин
той эпохи. Если ты когда-нибудь программировал звук на любой
из этих платформ — здесь всё будет знакомо.

Если нет — ничего страшного. Микросхема простая.

## Что умеет AY-3-8910

Три независимых канала тона. Каждый может генерировать
прямоугольную волну заданной частоты. Плюс один генератор шума,
который можно подмешивать к любому каналу. Плюс аппаратный
генератор огибающей, который управляет громкостью канала
по заданной кривой.

Итого: три голоса, шум, огибающая. Для музыки и звуковых
эффектов более чем достаточно.

Микросхема работает на тактовой частоте 1 МГц. Это важно
для расчёта частот нот.

## Как достучаться до AY

Прямого доступа к AY у Z80 нет. Микросхема подключена через
посредника — параллельный интерфейс 8255 (PPI). Это стандартная
схема в CPC.

У AY есть 16 внутренних регистров. Чтобы записать в один
из них, нужно:

1. Положить номер регистра на шину данных AY.
2. Установить управляющие сигналы BC1 и BDIR так, чтобы AY
   понял: «это адрес регистра».
3. Положить значение на шину данных.
4. Установить BC1 и BDIR так, чтобы AY понял: «это данные».

Шина данных AY подключена к порту A микросхемы 8255.
Управляющие сигналы BC1 и BDIR — к порту C.

Порты:

| Порт | Что | Назначение |
|------|-----|-----------|
| `#F4XX` | PPI Port A | Данные для AY |
| `#F6XX` | PPI Port C | Управление (BC1, BDIR) |

Биты порта C:

```
бит 7 — BDIR
бит 6 — BC1
```

Комбинации BC1/BDIR:

| BDIR | BC1 | Что делает |
|------|-----|-----------|
| 0 | 0 | Неактивно |
| 0 | 1 | Чтение данных из AY |
| 1 | 0 | Запись данных в AY |
| 1 | 1 | Запись адреса регистра в AY |

Порядок записи в регистр AY:

1. На порт A положить номер регистра (0–15).
2. На порт C выставить BDIR=1, BC1=1 (запись адреса).
3. На порт C выставить BDIR=0, BC1=0 (сброс).
4. На порт A положить значение.
5. На порт C выставить BDIR=1, BC1=0 (запись данных).
6. На порт C выставить BDIR=0, BC1=0 (сброс).

Это шесть шагов на одну запись. Муторно, но так работает
железо. В BIOS есть готовые функции `WR_PSG` и `RD_PSG`,
которые всё это делают за тебя. В Aleste рекомендуется
использовать именно их, а не дёргать порты напрямую.

## Регистры AY

Всего 16 регистров, с 0 по 15.

| Регистр | Что |
|---------|-----|
| 0 | Частота канала A, младший байт |
| 1 | Частота канала A, старшие 4 бита |
| 2 | Частота канала B, младший байт |
| 3 | Частота канала B, старшие 4 бита |
| 4 | Частота канала C, младший байт |
| 5 | Частота канала C, старшие 4 бита |
| 6 | Частота шума (5 бит) |
| 7 | Включение каналов и шума |
| 8 | Громкость канала A |
| 9 | Громкость канала B |
| 10 | Громкость канала C |
| 11 | Период огибающей, младший байт |
| 12 | Период огибающей, старший байт |
| 13 | Форма огибающей |
| 14 | Порт A (чтение) — клавиатура |
| 15 | Порт B (запись) — данные принтера |

Регистры 14 и 15 — это не звук, а дополнительный ввод-вывод
через AY. В Aleste регистр 15 используется для принтера
(см. раздел про порты), а регистр 14 — для чтения клавиатуры.

## Частота нот

Частота тона задаётся 12-битным значением: младшие 8 бит
в регистр `lo`, старшие 4 — в регистр `hi`. Микросхема
делит тактовую частоту (1 МГц) на это значение, получая
частоту выходного сигнала.

Формула:

```
частота_выхода = 1000000 / (16 * значение)
```

Отсюда:

```
значение = 1000000 / (16 * частота)
```

Например, для ноты «ля» первой октавы (440 Гц):

```
значение = 1000000 / (16 * 440) = 142
```

Это значение кладётся в регистры канала: младший байт (142)
и старшие 4 бита (0).

Пример: включить ноту 440 Гц на канале A.

```
; Устанавливаем частоту
LD A, 0            ; регистр 0 = младший байт частоты A
LD E, 142          ; значение
CALL WR_PSG        ; функция BIOS: записать E в регистр A

LD A, 1            ; регистр 1 = старшие 4 бита частоты A
LD E, 0
CALL WR_PSG

; Включаем канал A (бит 0 регистра 7)
LD A, 7
LD E, %00111110    ; канал A включён, B и C выключены, шум выключен
CALL WR_PSG

; Устанавливаем громкость канала A (регистр 8)
LD A, 8
LD E, 15           ; максимальная громкость
CALL WR_PSG
```

Готово, нота играет.

## Регистр 7: что включено

Этот регистр управляет тем, какие каналы и источники звука
активны.

| Бит | Что |
|-----|-----|
| 0 | Канал A: тон включён/выключен |
| 1 | Канал B: тон включён/выключен |
| 2 | Канал C: тон включён/выключен |
| 3 | Канал A: шум включён/выключен |
| 4 | Канал B: шум включён/выключен |
| 5 | Канал C: шум включён/выключен |
| 6 | Порт A: 0 = чтение, 1 = запись |
| 7 | Порт B: 0 = чтение, 1 = запись |

Для тона: бит = 0 включает тон, 1 выключает.
Для шума: бит = 0 включает шум, 1 выключает.

То есть логика инвертирована — не «1 значит включено»,
а «0 значит включено». Это классическая ловушка AY, о ней
нужно помнить.

Например, `%00111110` означает: канал A тон включён
(бит 0 = 0), каналы B и C тон выключены (биты 1 и 2 = 1),
шум на всех каналах выключен (биты 3, 4, 5 = 1).

## Громкость

Регистры 8, 9, 10 — громкость каналов A, B, C.

Значения:
- 0–15 — прямая громкость (0 = тихо, 15 = громко).
- 16 и выше — канал управляется огибающей.

Обычно используют 0–15, а огибающую — только когда нужно
автоматическое затухание или нарастание.

## Шум

Регистр 6 задаёт частоту шума, 5 бит (значения 0–31).
Чем меньше значение, тем выше частота шума (то есть
«шипение» более высокое). Чем больше — тем ниже, вплоть
до рокота.

Шум можно подмешать к любому каналу, установив
соответствующий бит в регистре 7. Это даёт разные эффекты:
ударные, взрывы, шипение.

## Огибающая

Огибающая — это автоматическое изменение громкости канала
по заданной кривой. Полезно для эффектов затухания, для
басовых линий, для «падающих» звуков.

Регистры:
- 11, 12 — период огибающей (16 бит).
- 13 — форма огибающей (16 вариантов).

Формы включают: пилу вверх, пилу вниз, треугольник, меандр,
одиночный импульс и их вариации. Полная таблица — в даташите
AY-3-8910, здесь приводить не буду: это редко нужно вручную,
обычно музыканты используют готовые трекеры.

Чтобы канал управлялся огибающей, надо записать в его
регистр громкости значение 16 или больше (обычно 16).

## Воспроизведение музыки

Вручную дёргать регистры AY для каждой ноты — неудобно.
Обычно музыка пишется в трекере, а потом проигрывается
программой-плеером, которая читает данные и обновляет
регистры AY с нужной частотой (обычно 50 Гц, по прерыванию
от развёртки).

Для Aleste существуют портированные трекеры и плееры
с CPC и MSX. Если нужна музыка — ищи готовый плеер,
не пиши свой с нуля.

## Стерео

В документации на Aleste упоминается «стерео». Но AY-3-8910 —
это моно микросхема. Три канала, но все они идут в один
выход.

Стерео в Aleste, скорее всего, реализовано внешними
средствами: например, отдельные каналы выводятся на разные
выходы через дополнительную обвязку. Но точной информации
об этом нет, и на уровне программирования AY остаётся
моно.

Если нужен настоящий стерео-звук — смотри в сторону
Magic Sound Board (см. упоминание в разделе про расширения).
Это отдельная плата с DMA-звуком, но она не входит в базовую
комплектацию Aleste.

## Доступ к AY через BIOS

В Aleste BIOS есть две функции для работы с AY:

- `WR_PSG` — записать значение в регистр AY.
- `RD_PSG` — прочитать значение из регистра AY.

Точные адреса и параметры — в документации на BIOS.
Использовать их проще и надёжнее, чем дёргать порты 8255
напрямую.

Если BIOS недоступен (например, ты его выключил), можно
дёргать порты напрямую:

```
; Записать значение E в регистр A
; A = номер регистра, E = значение
WritePSG:
    PUSH AF
    LD A, 7
    OUT (#F6XX), A     ; настраиваем порт C на выход
    POP AF
    ; ... (дальше последовательность BC1/BDIR)
```

Но это долго, муторно и легко ошибиться. BIOS-функции
для того и сделаны, чтобы этим не заниматься.

## Практические советы

**Используй BIOS-функции.** `WR_PSG` и `RD_PSG` — твои друзья.

**Помни про инверсию в регистре 7.** 0 включает, 1 выключает.
Это неочевидно и часто становится источником «почему не играет».

**Не забудь про громкость.** Часто забывают выставить регистр 8,
и нота «играет», но её не слышно.

**Для музыки — готовый плеер.** Не пиши свой трекер, если
не хочешь потратить месяц.

**Осторожно с огибающей.** Формы огибающей — это отдельная
тема, и без даташита легко запутаться.
