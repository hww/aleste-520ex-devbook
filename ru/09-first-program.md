# 08. Первая программа

Вот мы и добрались до практики. В предыдущих разделах
мы разобрали память, экран, звук, порты, клавиатуру
и дисковод по отдельности. Теперь соберём всё вместе
и напишем программу, которая что-то делает.

Программа будет простой, но не тривиальной. Она:

1. Переключит машину в Aleste-режим (MAPMOD = 1).
2. Настроит палитру.
3. Выберет режим экрана.
4. Выведет строку текста.
5. Зациклится, чтобы результат было видно.

Каждый шаг с комментариями: почему именно так, что
происходит, на что обратить внимание.

## Что нужно, чтобы собрать и запустить

Прежде чем писать код, нужно понять, как его
собрать и запустить.

**Ассемблер.** Для Z80 есть несколько вариантов:

- **z80asm** — простой, кроссплатформенный.
- **SjASMPlus** — популярный, много возможностей.
- **Pasmo** — ещё один хороший вариант.
- **WinAPE** — встроенный ассемблер в эмуляторе.

Любой из них подойдёт. Синтаксис немного отличается,
но базовые вещи одинаковые.

**Эмулятор.** Для Aleste готового эмулятора может
не быть (машина редкая). Но многие CPC-эмуляторы
поддерживают расширения Aleste. Например, **WinAPE**
или **CPCEC** могут работать с Aleste-режимом,
если правильно настроены.

Если эмулятора нет — можно запустить на реальной
машине. Загрузка через дискету или через RS-232.

**Формат вывода.** Обычно ассемблер выдаёт бинарный
файл. Его можно загрузить в эмулятор напрямую
или записать на дискету в формате AMSDOS.

## Куда грузить программу

`ORG 0x4000` — это **адрес в логической странице 1**
(`0x4000–0x7FFF`). Но какая **физическая** страница
замаплена в эту логическую — зависит от того, как
запущена программа. В `ROM.MAC` `BOOT` грузит
`BIOS.SYS` в **страницу 8** (`#7DC8`), `BDOS.SYS` —
в **страницу 9** (`#7DC9`). Если твоя программа
запускается вместо BIOS/BDOS, она должна сама
позаботиться о том, чтобы в странице 1 была
**свободная** страница RAM (например, 4 или 5).

Для примера будем считать, что программа загружена
в **страницу 4**, замапленную на `0x4000`. Тогда
`ORG 0x4000` корректен, а `0x4000` — начало кода.

## Структура программы

Любая программа для Z80 начинается с адреса, по
которому её загрузили. В нашем случае это `0x4000`
в странице 1.

Программа будет состоять из:

1. Точка входа — с неё начинается выполнение.
2. Инициализация — настройка режима, палитры, экрана.
3. Основной код — вывод текста.
4. Зацикливание — чтобы программа не завершилась.
5. Данные — строка текста, таблица шрифта.

## Код

Вот полный код программы. Потом разберём каждую
часть.

```asm
; ============================================
; Первая программа для Aleste 520EX
; Выводит строку "HELLO, ALESTE!" в Aleste-режиме
; ============================================

ORG 0x4000

; --- Точка входа ---
Start:
    ; 1. Переключаемся в Aleste-режим (MAPMOD = 1)
    ;    Порт #FABF, бит 2
    ;    Остальные биты: D0=0 (VRAM bank 0), D1=0 (norm res),
    ;    D2=1 (MAPMOD), D3=0 (MAP page 0), D4=0 (580WI53),
    ;    D5=0 (AY8910)
    LD BC, #FABF
    LD A, %00000100    ; бит 2 = 1 (MAPMOD)
    OUT (C), A

    ; 2. Настраиваем палитру
    CALL SetPalette

    ; 3. Выбираем режим экрана
    CALL SetMode

    ; 4. Выводим строку текста
    LD HL, Message     ; адрес строки
    CALL PrintString

    ; 5. Зацикливаемся
Loop:
    JR Loop

; ============================================
; Процедура: установка палитры
; Цвет 0 = чёрный, цвет 1 = белый
; ============================================
SetPalette:
    ; Выбираем регистр 0 Gate Array (palette index)
    LD BC, #7F00
    LD A, %00000000    ; биты 7,6 = 00
    OUT (C), A
    LD A, 0            ; индекс 0
    OUT (C), A

    ; Выбираем регистр 1 Gate Array (palette data)
    LD A, %01000000    ; биты 7,6 = 01
    OUT (C), A
    LD A, %00000000    ; цвет 0: R=0, G=0, B=0 (чёрный)
    OUT (C), A

    ; Теперь настроим цвет 1 (белый)
    LD A, %00000000    ; регистр 0 (index)
    OUT (C), A
    LD A, 1            ; индекс 1
    OUT (C), A

    LD A, %01000000    ; регистр 1 (data)
    OUT (C), A
    LD A, %00111111    ; цвет 1: R=3, G=3, B=3 (белый)
    OUT (C), A

    RET

; ============================================
; Процедура: установка режима экрана
; ============================================
SetMode:
    ; Регистр 2 Gate Array (RMR): mode, ROM, LEDs
    LD BC, #7F00
    LD A, %10000000    ; биты 7,6 = 10
    OUT (C), A

    ; Режим 1 (320x200, 4 цвета), нижний ROM выключен,
    ; верхний ROM выключен.
    ; Формат RMR: %10xxxxxx
    ;   бит 5 = CAPS LED (0)
    ;   бит 4 = RUS LED (0)
    ;   бит 3 = 1 -> upper ROM disable
    ;   бит 2 = 1 -> lower ROM disable
    ;   биты 1,0 = 01 -> mode 1
    LD A, %10001101    ; RMR, ROM выкл, mode 1
    OUT (C), A

    RET

; ============================================
; Процедура: вывод строки текста
; Вход: HL = адрес строки (0-терминированной)
; Вывод в позицию (0,0) экрана
; ============================================
PrintString:
    LD B, 0            ; X = 0
    LD C, 0            ; Y = 0
PrintLoop:
    LD A, (HL)
    OR A
    RET Z              ; конец строки
    CALL PrintChar
    INC HL
    INC B              ; следующий символ по X
    JR PrintLoop

; ============================================
; Процедура: вывод одного символа 8x8
; Вход: A = код символа, B = X (в символах), C = Y (в строках)
; Использует таблицу шрифта Font8x8 (8 байт на символ)
; ============================================
PrintChar:
    PUSH HL
    PUSH BC
    PUSH DE

    ; HL = адрес шрифта для символа A
    ; шрифт: 8 байт на символ, начиная с Font8x8
    LD L, A
    LD H, 0
    ADD HL, HL         ; *2
    ADD HL, HL         ; *4
    ADD HL, HL         ; *8
    LD DE, Font8x8
    ADD HL, DE         ; HL = адрес 8 байт символа

    ; DE = адрес в видеопамяти для (X=B, Y=C), режим 1
    ; Формула для 16 КБ режима 1:
    ;   addr = 0xC000 + (Y & 7) * 2048 + (Y >> 3) * 80 + X * 2
    ; (символ 8 пикселей, 2 бита на пиксель -> 2 байта на символ)
    PUSH HL
    LD A, C
    AND 7
    LD L, A
    LD H, 0
    ADD HL, HL         ; *2
    ADD HL, HL         ; *4
    ADD HL, HL         ; *8
    ADD HL, HL         ; *16
    ADD HL, HL         ; *32
    ADD HL, HL         ; *64
    ADD HL, HL         ; *128
    ADD HL, HL         ; *256
    ADD HL, HL         ; *512
    ADD HL, HL         ; *1024
    ADD HL, HL         ; *2048
    PUSH HL
    LD A, C
    SRL A
    SRL A
    SRL A              ; A = Y >> 3
    LD L, A
    LD H, 0
    ; L * 80 = L * 64 + L * 16
    LD D, H
    LD E, L
    SLA E
    RL D
    SLA E
    RL D               ; DE = L * 4
    SLA E
    RL D
    SLA E
    RL D               ; DE = L * 16
    PUSH DE
    SLA E
    RL D
    SLA E
    RL D               ; DE = L * 64
    POP HL             ; HL = L * 16
    ADD HL, DE         ; HL = L * 80
    POP DE             ; DE = (Y & 7) * 2048
    ADD HL, DE         ; HL = (Y&7)*2048 + (Y>>3)*80
    ; X * 2
    LD A, B
    ADD A, A           ; A = X * 2
    LD E, A
    LD D, 0
    ADD HL, DE
    ; HL = адрес в видеопамяти
    LD A, H
    AND 0x3F
    OR 0x40
    LD H, A            ; HL = 0x4000..0x7FFF (VRAM)
    POP DE             ; DE = адрес шрифта
    ; теперь DE = шрифт, HL = VRAM

    ; Копируем 8 строк по 2 байта
    LD B, 8
CharLoop:
    LD A, (DE)         ; байт шрифта (8 пикселей)
    LD (HL), A         ; в VRAM
    INC DE
    INC HL
    ; вторая половина символа (в режиме 1 символ = 2 байта)
    ; для простоты дублируем: второй байт = тот же
    LD A, (DE)         ; следующий байт шрифта (если шрифт 8 байт)
    LD (HL), A
    INC DE
    INC HL
    ; переход на следующую растровую строку: +0x800
    LD A, H
    ADD A, 0x08
    LD H, A
    AND 0x38
    JR NZ, CharNoWrap
    LD A, H
    SUB 0x40
    LD H, A
    LD A, L
    ADD A, 0x50
    LD L, A
    JR NC, CharNoWrap
    INC H
CharNoWrap:
    DEC B
    JR NZ, CharLoop

    POP DE
    POP BC
    POP HL
    RET

; ============================================
; Данные
; ============================================
Message:
    DB "HELLO, ALESTE!", 0

; Простой шрифт 8x8 для символов, которые используются
; в строке. Каждый символ — 8 байт (по байту на строку).
; Для символов, которых нет в таблице, будет мусор —
; это нормально для демонстрации.
;
; Таблица покрывает: пробел, запятую, восклицательный знак,
; буквы A,E,H,L,O,S,T и заглавные латинские.
Font8x8:
    ; ' ' (0x20)
    DB 0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00
    ; '!' (0x21)
    DB 0x18,0x18,0x18,0x18,0x18,0x00,0x18,0x00
    ; '"' (0x22) — не используется, заглушка
    DB 0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00
    ; '#' (0x23) — заглушка
    DB 0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00
    ; '$' (0x24) — заглушка
    DB 0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00
    ; '%' (0x25) — заглушка
    DB 0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00
    ; '&' (0x26) — заглушка
    DB 0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00
    ; '\'' (0x27) — заглушка
    DB 0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00
    ; '(' (0x28) — заглушка
    DB 0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00
    ; ')' (0x29) — заглушка
    DB 0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00
    ; '*' (0x2A) — заглушка
    DB 0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00
    ; '+' (0x2B) — заглушка
    DB 0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00
    ; ',' (0x2C)
    DB 0x00,0x00,0x00,0x00,0x00,0x18,0x18,0x30
    ; '-' (0x2D) — заглушка
    DB 0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00
    ; '.' (0x2E) — заглушка
    DB 0x00,0x00,0x00,0x00,0x00,0x00,0x18,0x00

    DB 0x00,0x00,0x00,0x00,0x00,0x00,0x00,0x00
```

## Разбор кода

Теперь по шагам.

### Шаг 1: переключение в Aleste-режим

```asm
LD BC, #FABF
LD A, %00000100
OUT (C), A
```

Порт `#FABF` — это EXTPORT. Бит 2 — MAPMOD. Устанавливаем
его в 1, получаем Aleste-режим: 64 цвета, расширенный
маппер.

Остальные биты оставляем 0:

- **D0 = 0** — VRAM bank 0.
- **D1 = 0** — normal resolution (не HIGHX).
- **D2 = 1** — MAPMOD (Aleste-маппер).
- **D3 = 0** — MAP page 0.
- **D4 = 0** — 580WI53 (таймер).
- **D5 = 0** — AY8910 (а не 512WI1).

Это важный шаг: без него машина останется в CPC-режиме,
и палитра будет 27-цветной, а не 64-цветной.

### Шаг 2: настройка палитры

Палитра настраивается через Gate Array (порт `#7F00`).
Сначала выбираем индекс (какой цвет менять), потом
пишем данные.

```asm
LD BC, #7F00
LD A, %00000000    ; регистр 0 — palette index
OUT (C), A
LD A, 0            ; индекс 0
OUT (C), A
```

Первая запись выбирает регистр 0 Gate Array
(биты 7,6 = 00). Вторая запись — данные для
регистра 0, то есть номер индекса палитры.

Потом выбираем регистр 1 и пишем цвет:

```asm
LD A, %01000000    ; регистр 1 — palette data
OUT (C), A
LD A, %00000000    ; цвет: R=0, G=0, B=0 (чёрный)
OUT (C), A
```

Цвет кодируется шестью битами: два на красный, два
на зелёный, два на синий. `%00000000` — все нули,
чёрный. Для белого — `%00111111` (R=3, G=3, B=3).

### Шаг 3: выбор режима

Режим выбирается через регистр 2 Gate Array (RMR).

```asm
LD A, %10000000    ; регистр 2
OUT (C), A
LD A, %10001101    ; RMR, ROM выкл, mode 1
OUT (C), A
```

Биты 7,6 = 10 выбирают регистр 2. Биты 1,0 = 01 —
режим 1 (320×200, 4 цвета). Бит 3 = 1 — верхний ROM
**выключен**. Бит 2 = 1 — нижний ROM **выключен**.

Зачем выключать ROM? Затем, что мы работаем
в собственной программе и не хотим, чтобы BIOS
вмешивался. В реальной программе это может быть
не нужно — зависит от задачи.

### Шаг 4: вывод текста

Процедура `PrintString` читает строку по адресу HL
и для каждого символа вызывает `PrintChar`, который:

1. Берёт 8 байт шрифта из `Font8x8` (по коду символа).
2. Вычисляет адрес в видеопамяти по формуле для
   режима 1 (16 КБ):

   ```asm
   addr = 0xC000 + (Y & 7) * 2048 + (Y >> 3) * 80 + X * 2
   ```

3. Копирует 8 строк шрифта в VRAM, переходя между
   растровыми строками через `+0x800`.

В примере шрифт содержит только те символы, которые
используются в строке «HELLO, ALESTE!». Остальные
символы — заглушки (нули). В реальной программе
шрифт был бы полным (256 символов) или брался бы
из ROM через `ALEST`.

### Шаг 5: зацикливание

```asm
Loop:
    JR Loop
```

Программа завершается бесконечным циклом. Если этого
не сделать, процессор пойдёт дальше по памяти, наткнётся
на случайные данные и упадёт.

В реальной программе здесь был бы возврат в BIOS
или в BASIC. Но для примера — цикл.

## Что улучшить

Этот пример намеренно упрощён. В реальной программе
нужно:

**Использовать полный шрифт.** В примере шрифт
содержит только несколько символов. В реальной
программе бери шрифт из ROM (`ALEST`) или
используй полную таблицу 256 символов.

**Учитывать нелинейность видеопамяти для всех
режимов.** В примере — формула для режима 1
(16 КБ). Для режимов 0, 2, 3 и HIGHX формулы
другие (см. раздел «03. Экран»).

**Обрабатывать прерывания.** Если программа работает
с прерываниями, их нужно настроить. Для простого
примера это не нужно.

**Восстанавливать состояние.** Если программа
завершается, она должна вернуть машину в исходное
состояние: восстановить ROM, вернуть MAPMOD = 0,
восстановить палитру.

**Проверять ошибки.** В примере нет проверок, но
в реальной программе они нужны.

## Как собрать и запустить

1. Сохрани код в файл `hello.asm`.
2. Собери ассемблером. Например, для z80asm:

   ```asm
   z80asm -o hello.bin hello.asm
   ```

3. Загрузи `hello.bin` в эмулятор в **страницу 4**,
   замапленную на `0x4000`. (Или в любую свободную
   страницу, но тогда поправь `ORG` и адрес загрузки.)
4. Установи точку входа на `0x4000`.
5. Запусти.

Если всё сделано правильно — на экране появится
строка «HELLO, ALESTE!».
