# 02-keyboard.md — Драйвер клавиатуры (BIOS.DRV)

## Назначение

Сканирует матрицу клавиатуры по прерыванию 50 Гц, преобразует нажатия в виртуальные коды, хранит их в кольцевом буфере `KEYBUF` и предоставляет доступ либо к буферу (высокий уровень), либо к матрице напрямую (низкий уровень). В отличие от CPC, где клавиатура сканируется через PPI и `KM_*` функции, здесь **матрица опрашивается программно** через порты `0F4xx`/`0F6xx`, а преобразование в ASCII делается по таблицам `NORMTAB`/`SHIFTAB`/`RUSTAB`/`SHRUSTAB` .

Драйвер поддерживает модификаторы (`CAPS`, `RUS`, `Shift`, `Ctrl`, `Alt`), автоповтор с настраиваемой задержкой и частотой, а также звуковой отклик клавиш.

**Исходник:** `BIOS.DRV` (подключается через `INCLUDE BIOS.DRV` в `BIOS.MAC`).

---

## Инициализация

### `KEY_INIT` (`L00ED`)

Инициализация драйвера. Копирует `KEYINITAB` в рабочую область (`OLDKEY`…`KEYMOD`), сбрасывает состояние матрицы в `FFH` (все клавиши отпущены), обнуляет буфер и счётчики.

```
Вход:  —
Выход: —
Изменяет: все регистры
```
Вызывается из `INIT` BIOS. Вручную не вызывать.

---

## Высокоуровневый ввод

### `READ_KEY` (`L00F6`)

Чтение одной клавиши из буфера **без блокировки**. Возвращает виртуальный код (не ASCII) и модификаторы.

```
Вход:  —
Выход: A = C = виртуальный код клавиши (0 = буфер пуст, ZF=1)
       B = модификаторы: bit3 CAPS, bit4 RUS, bit5 Shift, bit6 Ctrl, bit7 Alt
Изменяет: AF, BC, DE, HL
```
Виртуальный код — это **индекс в таблице** (`NORMTAB` и др.), а не ASCII. Для получения ASCII используйте `INPUT`/`INKEY`, либо преобразуйте вручную через `TABCOD1`…`TABCOD4`.

**Пример (опрос без ожидания):**
```asm
    CALL L00F6      ; READ_KEY
    JR   Z,NO_KEY   ; ZF=1 — буфер пуст
    ; A = код клавиши, B = модификаторы
```

---

### `INPUT` (`L0010`)

Блокирующий ввод с выводом курсора и звуковым откликом. Ждёт, пока в буфере появится клавиша, затем преобразует её в ASCII через таблицы.

```
Вход:  —
Выход: A = ASCII-код
Изменяет: AF, BC, DE, HL
```
Выводит курсор (`PLACE_CUR`) перед ожиданием и гасит (`ERASE_CUR`) после. Если включён звук (`MODECUR` bit5), издаёт короткий писк через AY8910.

**Пример:**
```asm
    CALL L0010      ; ждать нажатия, A = ASCII
    CP   'Q'
    JR   Z,QUIT
```

---

### `INKEY` (`L0008`)

Неблокирующий ввод с преобразованием в ASCII. Если буфер пуст — `A=0`.

```
Вход:  —
Выход: A = ASCII-код (0 = нет нажатия)
Изменяет: AF, BC, DE, HL
```
Не выводит курсор и не пищит. Вызывает хук `XFDCC` (INKEY hook) перед чтением.

**Пример (игровой цикл):**
```asm
LOOP:
    CALL L0008      ; INKEY
    AND  A
    JR   Z,LOOP     ; нет нажатия — продолжаем
    CP   1BH        ; ESC?
    JR   Z,EXIT
    JR   LOOP
```

---

### `TEST_KEY` (`L00F9`)

Проверка конкретной клавиши по виртуальному коду.

```
Вход:  A = виртуальный код клавиши
Выход: ZF=1 если нажата
Изменяет: AF
```
Внутри вызывает `SNSMAT` для нужной строки и проверяет бит.

**Пример (проверка Shift):**
```asm
    LD   A,15H      ; код Shift
    CALL L00F9
    JR   Z,SHIFT_DOWN
```

---

### `BREAK` (`L00FC`)

Проверка `Ctrl+C` (прерывание).

```
Вход:  —
Выход: CF=1 если нажат Ctrl+C
Изменяет: AF
```
Проверяет `Ctrl` (код `17H`) и `C` (код `3EH`) через `TEST_KEY`. Используется в `LPTOUT` и `COM_IN` для прерывания длительных операций.

---

## Буфер клавиатуры

### `TST_KEYBUF` (`L00F0`)

Проверка, пуст ли буфер.

```
Вход:  —
Выход: ZF=1 если буфер пуст
Изменяет: AF
```
Сравнивает `GETKEY` и `PUTKEY`. Если равны — буфер пуст.

---

### `CLR_KEYBUF` (`L00F3`)

Очистка буфера. Устанавливает `GETKEY = PUTKEY = KEYBUF`.

```
Вход:  —
Выход: —
Изменяет: HL
```

---

## Низкоуровневый доступ к матрице

### `SNSMAT` (`L014D`)

Чтение одной строки матрицы клавиатуры. Это **единственный** способ опросить матрицу напрямую.

```
Вход:  D = номер строки (0–10)
Выход: E = данные (бит = 0 означает нажатие)
Изменяет: AF
```
Матрица 11 строк × 8 столбцов. Номер строки `D` соответствует строкам `NEWKEY`/`OLDKEY` (смещение `D` от начала). Бит 7 — крайняя левая клавиша в строке, бит 0 — крайняя правая (зависит от раскладки).

**Пример (из `TKEY1.MAC` — проверка Shift при старте):**
```asm
    LD   D,2
    CALL L014D      ; SNSMAT
    BIT  5,E        ; Shift?
    JR   NZ,NO_SHIFT
    ; Shift нажат — грузим Aleste
```

**Пример (опрос всей матрицы):**
```asm
    LD   HL,NEWKEY
    LD   D,0
LOOP:
    CALL L014D
    LD   (HL),E
    INC  HL
    INC  D
    LD   A,D
    CP   11
    JR   NZ,LOOP
```

## Таблицы кодов клавиш

Драйвер использует четыре таблицы, адреса которых хранятся в `TABCOD1`…`TABCOD4`. Каждая запись — байт-длина и слово-адрес.

### `SET_NORM` / `GET_NORM` (`L00FF` / `L0102`)

Установка/чтение таблицы обычных клавиш (`NORMTAB`).

```
Вход:  HL = адрес таблицы (SET_NORM)
Выход: HL = адрес (GET_NORM), A = длина
```

---

### `SET_SHIFT` / `GET_SHIFT` (`L0105` / `L0108`)

Таблица клавиш с `Shift` (`SHIFTAB`).

---

### `SET_RUS` / `GET_RUS` (`L010B` / `L010E`)

Таблица русских клавиш (`RUSTAB`).

---

### `SET_SHRUS` / `GET_SHRUS` (`L0111` / `L0114`)

Таблица русских клавиш с `Shift` (`SHRUSTAB`).

---

## Настройка сканирования и автоповтора

### `SET_SCAN` / `GET_SCAN` (`L0117` / `L011A`)

Счётчик сканирования: как часто `KEY_SCAN` вызывается в прерывании 50 Гц. `1` = каждый кадр, `2` = каждый второй и т.д.

```
Вход:  A = значение (SET_SCAN)
Выход: (GET) A = значение
```
По умолчанию `1`.

---

### `SET_REPT` / `GET_REPT` (`L011D` / `L0120`)

Счётчик автоповтора: как часто повторяется нажатая клавиша (в кадрах после задержки).

```
Вход:  A = значение (SET_REPT)
Выход: (GET) A = значение
```
По умолчанию `2`.

---

### `SET_DELAY` / `GET_DELAY` (`L0123` / `L0126`)

Задержка перед началом автоповтора (в кадрах).

```
Вход:  A = значение (SET_DELAY)
Выход: (GET) A = значение
```
По умолчанию `16` (≈320 мс при 50 Гц). `INIT` устанавливает `16` явно.

---

## Звук клавиш

### `CLICKON` / `CLICKOFF` (`L0129` / `L012C`)

Включение/выключение звукового отклика (бит 5 `MODECUR`).

```
Вход:  —
Выход: —
Изменяет: AF
```
Звук издаётся в `INPUT` через AY8910 (канал A, регистры `08H`/`09H`).

---

## Внутреннее устройство (для понимания)

### `KEYB_SCAN`

Сканирует всю матрицу и записывает результат в `NEWKEY` (11 байт). Вызывается из `KEY_SCAN`.

### `KEY_SCAN`

Сравнивает `NEWKEY` с `OLDKEY`, определяет **новые** нажатия (бит, который был `1`, стал `0`), и для каждого нового нажатия вызывает `KEY_SCN`. Также обновляет `KEYMOD` (модификаторы) и `REPCNT` (задержка автоповтора).

### `KEY_SCN`

Для одной строки матрицы перебирает 8 бит. Если бит = 0 (нажатие), вызывает `KEY_SCN2`.

### `KEY_SCN2`

Проверяет, не модификатор ли это (`Alt`, `Shift`, `Ctrl`, `CAPS`, `RUS`). Если да — обрабатывает специально (`CAPS`/`RUS` переключают флаги в `KEYMOD` и лампу/звук). Иначе кладёт **виртуальный код** (индекс `C`) в `KEYBUF` через `GETKEY`.

### `INP_KEY`

Берёт код из буфера, выбирает таблицу по `KEYMOD` (RUS/Shift), читает ASCII через `RDSLT` (таблица может быть в другой странице памяти), применяет `Ctrl` (вычитает `40H`) и `CAPS` (инвертирует регистр).

## Переменные драйвера

| Адрес | Имя | Назначение |
|-------|-----|-----------|
| `0FE8FH` | `OLDKEY` | Прошлое состояние матрицы (11 байт) |
| `0FE9AH` | `NEWKEY` | Новое состояние матрицы (11 байт) |
| `0FEA5H` | `KEYBUF` | Кольцевой буфер нажатых клавиш (40 байт) |
| `0FECDH` | `INTFLAG` | Флаг кадрового прерывания |
| `0FECEH` | `SCNCNT` | Счётчик сканирования |
| `0FECFH` | `REPCNT` | Счётчик автоповтора |
| `0FED0H` | `BEEPCNT` | Счётчик звука клавиш |
| `0FED1H` | `GETKEY` | Указатель записи в `KEYBUF` |
| `0FED3H` | `PUTKEY` | Указатель чтения из `KEYBUF` |
| `0FED5H` | `TABCOD1` | Таблица `NORMTAB` |
| `0FED8H` | `TABCOD2` | Таблица `SHIFTAB` |
| `0FEDBH` | `TABCOD3` | Таблица `RUSTAB` |
| `0FEDEH` | `TABCOD4` | Таблица `SHRUSTAB` |
| `0FEE1H` | `SCAN` | Скорость сканирования |
| `0FEE2H` | `REPEAT` | Скорость автоповтора |
| `0FEE3H` | `DELAY` | Задержка автоповтора |
| `0FEE4H` | `KEYMOD` | Состояние модификаторов: bit3 CAPS, bit4 RUS, bit5 Shift, bit6 Ctrl, bit7 Alt |

---

## Хуки

| Адрес | Имя | Когда вызывается |
|-------|-----|------------------|
| `0FDBDH` | `XFDBD` | Keyboard Interrupt hook — в `KEY_REPEAT`, перед обработкой |
| `0FDССH` | `XFDCC` | INKEY hook — в `INKEY`, перед чтением |
| `0FDD1H` | `XFDD1` | INPUT hook — в `INPUT`, перед ожиданием |
