# README.md — BIOS Aleste 520 EX

## Что это

BIOS Aleste 520 EX — это не одна прошивка, а **загружаемый модуль**, который живёт в ОЗУ и переключается вместе с режимом машины. В режиме Amstrad вы работаете с Amstrad BIOS из нижнего ПЗУ (страница 0). В режиме Aleste (`MAPMOD=1`) в адресное пространство подключаются страницы ОЗУ с кодом BIOS, и вы вызываете его через **таблицу векторов в начале памяти** — точно так же, как на MSX или CPC, но с другой начинкой .

Aleste — клон Amstrad CPC 6128, разработанный в Омске в 1993 году. Он умеет притворяться CPC, но под этим притворством скрывается машина с MSX-совместимым маппером памяти, 64-цветной палитрой, RTC и последовательным портом .

## Карта памяти: три уровня

### 1. Векторы BIOS (`0000H`–`0165H`)

С адреса `0000H` идёт таблица `JP`-инструкций. **Вызывайте только векторы, никогда не адреса за ними** — внутренние адреса меняются от версии к версии.

```asm
L0000: JP INIT        ; инициализация BIOS
L0008: JP INKEY       ; неблокирующий ввод
L0018: JP SYMBOL      ; вывод символа
...
L0069: JP SCR_INIT    ; инициализация экрана
L00ED: JP KEY_INIT    ; инициализация клавиатуры
L0135: JP MOUS_INIT   ; инициализация мыши
L0153: JP COM_INI     ; инициализация RS-232
```

Полный список — в `BIOS.MAC`, строки `L0000`–`L0165`. Каждый вектор ведёт в конкретный драйвер, описанный в отдельном документе.

### 2. Рабочая область (`0FC00H`–`0FFE0H`)

Все переменные BIOS лежат в верхней части адресного пространства — аналог «системных переменных» MSX. Читать можно, писать без необходимости — нельзя.

| Адрес             | Что там                                  | Документ                         |
|-------------------|------------------------------------------|----------------------------------|
| `0FC00H`          | `GR` — таблица параметров графики        | [06-graphics.md](06-graphics.md) |
| `0FCE2H`          | `WORKSPC` — стек BIOS                    | —                                |
| `0FD90H`–`0FDDBH` | Хуки (NMI, Timer, RS-232, KBD, Mouse, …) | [08-errata.md](08-errata.md)     |
| `0FDF5H`          | `EXTPORT` — теневой порт `0FABF`         | —                                |
| `0FE09H`/`0FE0AH` | `CSRY`/`CSRX` — курсор                   | [01-screen.md](01-screen.md)     |
| `0FE14H`/`0FE15H` | `INK`/`PAPER` — цвета                    | [01-screen.md](01-screen.md)     |
| `0FEA5H`          | `KEYBUF` — буфер клавиш                  | [02-keyboard.md](02-keyboard.md) |
| `0FEE9H`/`0FEEBH` | `MOUS_X1`/`MOUS_Y1` — мышь               | [03-mouse.md](03-mouse.md)       |

### 3. Хуки (`0FD90H`–`0FDDBH`)

Пятибайтовые области, инициализированные как `RET`. BIOS вызывает их в ключевых точках. Чтобы вклиниться — запишите `JP ваш_код` или `RST 30H` с номером страницы (техника MSX ). Список хуков — в `BIOS.MAC`.

**Важно:** `BIOS.GRP` и `BIOS.SPR` **не подключены** к `BIOS.MAC` через `INCLUDE` в текущем комплекте. Это библиотеки, которые линкуются отдельно, если нужна графика.

## Известные проблемы

Комплект **неполон**. Главное: `BIOS.DRV` обрезан на `CTS_INT`, отсутствуют `COM_OUT`, `COM_IN`, `COM_OUT_ST`, `COM_IN_ST`, `RX_INT`, `TX_INT`, `TEST_TX`. Без них `BIOS.MAC` не линкуется. Подробности и обходные пути — в [08-errata.md](08-errata.md).

## Сборка (ориентировочно)

```
BIOS.MAC  ──INCLUDE──► BIOS.SCR
          ──INCLUDE──► BIOS.DRV
          ──INCLUDE──► (BIOS.GRP, BIOS.SPR — добавить вручную)
          ──EXTRN───► ALEST (шрифт, отсутствует)
ROM.MAC   ──EXTRN───► DATA (заставка, отсутствует), ALEST
```

Скрипт для сболки

```bash
M80=BIOS
L80 /P:0,BIOS,PGT,BIOS/N/E
DEL BIOS.REL
COPY BIOS.COM A:BIOS.SYS
A:RESET
```
