Welcome! This repository is dedicated to creating a clean, human-oriented, and comprehensive development guide for the **Aleste 520EX** computer and its modern re-imagining, the **Aleste LX**.

### Why this repo exists?

For a long time, documentation for the Aleste was either incomplete, scattered across ancient notes, or heavily mixed with standard Amstrad CPC reference manuals. For a practical developer who just wants to write or port a game, understanding how the Aleste memory mappers, video modes, or MagicSound DMA engine actually work was a nightmare.

This project aims to bridge the gap. We are building a **DevBook**—a practical architectural guide focused on the creator, filled with concepts, register maps, and coding patterns, rather than just raw hardware tables.

### 🔄 Contribution & Sync Rules

To keep our documentation accurate for everyone, we follow these simple rules:

* **Two Languages, One PR:** Any change to the English text (`./en/`) **must** be accompanied by a matching change to the Russian text (`./ru/`) within the *same* Pull Request (and vice versa).
* **AI Translation Allowed:** If you don't speak one of the languages, use AI (ChatGPT, DeepL, etc.) to make a draft translation. The maintainers will review and polish it.
* **Atomic Commits:** Keep your documentation changes small and self-contained so that the second language can be easily added and verified during review.

Добро пожаловать! Этот репозиторий создан для того, чтобы собрать понятное, структурированное и ориентированное на человека руководство по программированию оригинального компьютера **Aleste 520EX** и его современной ПЛИС-модификации **Aleste LX**.

### Зачем нужен этот проект?

Долгое время документация по Алесте существовала в виде разрозненных заметок «для себя» или сухих отсылок к архитектуре Amstrad CPC. Практикующему разработчику, который хочет написать или портировать игру, было безумно сложно разобраться, как на самом деле управлять мапперами памяти, переключать новые видеорежимы высокого разрешения или запускать DMA-звук на MagicSound.

Этот репозиторий призван решить проблему. Мы пишем **DevBook** — практический путеводитель по архитектуре, развернутый лицом к программисту, с объяснением логики работы железа и паттернов проектирования.

### 🔄 Правила обновления и синхронизации

Чтобы документация оставалась актуальной для всех, мы соблюдаем простые правила:

* **Два языка — один PR:** Любое изменение английского текста (`./en/`) **должно** сопровождаться аналогичным изменением русского текста (`./ru/`) в рамках *одного* Pull Request (и наоборот).
* **ИИ-перевод разрешен:** Если вы не знаете одного из языков, используйте ИИ (ChatGPT, DeepL и т.д.) для создания черновика перевода. Мейнтейнеры проверят и поправят его на этапе ревью.
* **Атомарные коммиты:** Делайте правки документации небольшими и изолированными. Так перевод на второй язык будет проще добавить и проверить при слиянии.
