# 03-mouse.md — Драйвер мыши (BIOS.DRV)

## Назначение

Принимает пакеты от последовательной мыши (MS Mouse или PC Mouse) через RS-232, обрабатывает их в прерывании RxRDY (`XFDAE`) и обновляет абсолютные координаты и состояние кнопок в рабочей области. Вы просто читаете результат — драйвер сам заботится о приёме, масштабировании и ограничении границами.

Это **не CPC-овская мышь** (на CPC 6128 её и не было). Это PC-мышь через RS-232, и `MOUS_INIT` настраивает ВВ51 и ВИ53 под конкретный протокол. Драйвер использует тот же порт, что и `COM_INI`, поэтому **нельзя одновременно использовать мышь и RS-232** без переключения.

**Исходник:** `BIOS.DRV` (подключается через `INCLUDE BIOS.DRV` в `BIOS.MAC`).

---

## Инициализация

### `MOUS_INIT` (`L0135`)

Инициализация драйвера мыши. Копирует `MOUS_TAB` в рабочую область (`MOUSFLG`…`MOUS_TIP`), настраивает ВВ51 (канал A в режим 3, скорость 1200 бод) и ВИ53, устанавливает обработчики прерываний `XFDAE` (RxRDY) и `XFDA4` (Error).

```
Вход:  A = тип: 1 = MS Mouse, 2 = PC Mouse
Выход: —
Изменяет: все регистры
```
Вызывается из `INIT` BIOS с `A=1` (PC Mouse). После инициализации драйвер **выключен** (`MOUSFLG=0`) — нужно вызвать `MOUS_ON`.

**Пример:**
```asm
    LD   A,1
    CALL L0135      ; MOUS_INIT (PC Mouse)
    CALL L0138      ; MOUS_ON
```

---

### `MOUS_ON` / `MOUS_OFF` (`L0138` / `L013B`)

Включение/выключение драйвера. При `MOUSFLG=0` обработчик прерывания сразу выходит, не трогая буфер.

```
Вход:  —
Выход: —
Изменяет: AF
```
`MOUS_OFF` не отключает прерывания ВВ51 — только игнорирует пакеты. Полезно для временного «замораживания» мыши.

---

## Чтение состояния

### `GET_MOUS` (`L013E`)

Возвращает текущие координаты, состояние кнопок и модификаторы клавиатуры.

```
Вход:  —
Выход: HL = X (0..Xmax)
       DE = Y (0..Ymax)
       A = кнопки: bit0 Left, bit1 Middle, bit2 Right
           + модификаторы: bit3 CAPS, bit4 RUS, bit5 Shift, bit6 Ctrl, bit7 Alt
Изменяет: все регистры
```
Координаты **абсолютные**, в диапазоне, заданном `SET_MLIM`. Начало координат — левый верхний угол (`0,0`).

**Пример (игровой цикл с мышью):**
```asm
LOOP:
    CALL L013E      ; GET_MOUS
    ; HL = X, DE = Y, A = кнопки
    BIT  0,A        ; левая кнопка?
    JR   NZ,CLICK
    ; ... отрисовка курсора в (HL,DE) ...
    JR   LOOP
```

---

### `SET_MOUS` (`L0150`)

Установка позиции мыши программно (без движения физической мыши).

```
Вход:  HL = X, DE = Y
Выход: —
Изменяет: все регистры
```
Полезно для центрирования курсора или «телепортации» после смены экрана.

---

## Границы и масштаб

### `SET_MLIM` (`L0141`)

Установка границ координат. Также **сбрасывает** текущую позицию в `(0,0)`.

```
Вход:  HL = Xmax, DE = Ymax
Выход: —
Изменяет: —
```
По умолчанию `Xmax=639`, `Ymax=199` (из `MOUS_TAB`). Для экрана 320×200 имеет смысл `Xmax=319`, `Ymax=199`.

**Пример:**
```asm
    LD   HL,319
    LD   DE,199
    CALL L0141      ; SET_MLIM
```

---

### `GET_MLIM` (`L0144`)

Возвращает текущие границы.

```
Вход:  —
Выход: HL = Xmax, DE = Ymax
Изменяет: —
```

---

### `SET_MSCAL` (`L0147`)

Установка масштаба: сколько «тиков» мыши приходится на один пиксель. Чем больше масштаб, тем медленнее движется курсор.

```
Вход:  H = X scale, L = Y scale
Выход: —
Изменяет: —
```
По умолчанию `1` (из `MOUS_TAB`). Значение `2` = курсор движется вдвое медленнее.

**Пример:**
```asm
    LD   HL,0202H   ; X scale = 2, Y scale = 2
    CALL L0147      ; SET_MSCAL
```

---

### `GET_MSCAL` (`L014A`)

Возвращает текущий масштаб.

```
Вход:  —
Выход: H = X scale, L = Y scale
Изменяет: —
```

---

## Внутреннее устройство (для понимания)

### Формат пакета

MS Mouse и PC Mouse используют **3-байтовый пакет**:

```
Байт 0: 1 0 0 LB RB Y7 Y6 X7 X6   (синхробиты + кнопки + старшие биты)
Байт 1: X7..X0 (знаковое приращение X)
Байт 2: Y7..Y0 (знаковое приращение Y)
```

`MOUS_INT` проверяет, что первый байт имеет `10xxxxxx` (синхробиты), иначе игнорирует. Пакеты складываются в `RX_BUF`, при накоплении 5 байт вызывается `MOUS_INT2`, который обновляет координаты.

### `MOUS_INT`

Обработчик RxRDY. Читает байт из порта `0EEH`, проверяет синхробиты, кладёт в `RX_BUF`. При переполнении буфера (`RX_BUF+5`) вызывает `MOUS_INT2`.

### `MOUS_INT2`

Разбирает 3-байтовый пакет:
- `IX+00` — кнопки и старшие биты
- `IX+01` — приращение X
- `IX+02` — приращение Y

Приращения **знаковые** (`JP M` для отрицательных). Для каждого приращения:
1. Добавляется к счётчику (`MOUS_X`/`MOUS_Y`).
2. Вычитается масштаб (`MOUS_SCLX`/`MOUS_SCLY`) в цикле, пока счётчик ≥ масштаба.
3. Каждое вычитание = +1 к координате.
4. Координата ограничивается `MOUS_XMAX`/`MOUS_YMAX`.

В конце вызывается хук `XFDC2` (Mouse move hook).

### `MOUS_ERR`

Обработчик ошибки RS-232 (вектор `XFDA4`). Сбрасывает буфер и состояние ВВ51.

## Переменные драйвера

| Адрес | Имя | Назначение |
|-------|-----|-----------|
| `0FEE5H` | `MOUSFLG` | `0` = выключено, `<>0` = включено |
| `0FEE6H` | `MOUS_K` | Состояние кнопок (bit0–2) |
| `0FEE7H` | `MOUS_Y` | Счётчик приращения Y |
| `0FEE8H` | `MOUS_X` | Счётчик приращения X |
| `0FEE9H` | `MOUS_Y1` | Абсолютная координата Y (word) |
| `0FEEBH` | `MOUS_X1` | Абсолютная координата X (word) |
| `0FEEDH` | `MOUS_YMAX` | Максимум Y (по умолчанию 199) |
| `0FEEFH` | `MOUS_XMAX` | Максимум X (по умолчанию 639) |
| `0FEF1H` | `MOUS_SCLY` | Масштаб Y (по умолчанию 1) |
| `0FEF2H` | `MOUS_SCLX` | Масштаб X (по умолчанию 1) |
| `0FEF3H` | `MOUS_TIP` | Тип мыши: 0 = PC, 1 = MS |

---

## Хуки

| Адрес | Имя | Когда вызывается |
|-------|-----|------------------|
| `0FDA4H` | `XFDA4` | RS-232 Error — перенаправляется на `MOUS_ERR` |
| `0FDAEH` | `XFDAE` | RS-232 RxRDY — перенаправляется на `MOUS_INT` |
| `0FDC2H` | `XFDC2` | Mouse move hook — в конце `MOUS_INT2` |

---

## Ограничения

1. **Мышь и RS-232 несовместимы.** Оба используют один и тот же ВВ51 и одни и те же буферы `RX_BUF`/`TX_BUF`. Если вы хотите использовать RS-232 для связи, сначала вызовите `MOUS_OFF`, затем `COM_INI`.

2. **Только 3-кнопочные и 2-кнопочные.** `MOUS_TIP` различает PC (2 кнопки) и MS (3 кнопки), но `MOUS_INT2` обрабатывает `MOUS_K` одинаково — биты 0–2.

3. **Нет колеса.** Драйвер не поддерживает колесо прокрутки (его не было в 1993 году).

4. **Границы сбрасываются при `SET_MLIM`.** Если вы хотите сохранить позицию, вызовите `SET_MOUS` после `SET_MLIM`.
